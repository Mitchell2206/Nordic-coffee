# Nordic Coffee · sitio web

Esta es la versión completa de la web de Nordic Coffee preparada para Vercel.

## Publicarla en Vercel

1. Descomprimí el archivo ZIP.
2. Subí la carpeta completa a un repositorio nuevo de GitHub.
3. En Vercel elegí **Add New → Project**.
4. Importá ese repositorio.
5. Vercel detectará Next.js automáticamente. No cambies los valores de configuración.
6. Presioná **Deploy**.

## Probarla en tu computadora

Necesitás Node.js 20 o superior. Desde la carpeta del proyecto ejecutá:

```bash
npm install
npm run dev
```

Después abrí `http://localhost:3000`.
